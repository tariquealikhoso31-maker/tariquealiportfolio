TARIQUE ALI - PORTFOLIO
=======================

HOW TO OPEN
  Double-click index.html. No installation needed.

FILES
  index.html      Home
  about.html      About (personal details + languages)
  education.html  Education
  skills.html     Skills
  projects.html   Projects
  contact.html    Contact
  css/style.css   All styling
  js/script.js    Menu, dark mode, project filter, contact form
  images/         Put your photo here as profile.jpg

THINGS TO UPDATE
  1. Add your photo: images/profile.jpg
  2. projects.html: replace the sample projects with your real ones,
     and change each href="#" to your live demo / GitHub links.
  3. skills.html: adjust the dots (class="on") to match your real level.

PUT IT ONLINE (free)
  GitHub Pages: create a repository, upload all these files,
  then Settings > Pages > Deploy from branch (main).
